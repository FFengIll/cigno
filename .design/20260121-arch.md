# Cigno Architecture

**Date**: 2026-01-21
**Status**: WIP (Work In Progress)

## Project Overview

Cigno is a fast container image builder that works without Docker daemon. It uses OCI operations (via `crane` from go-containerregistry) to build images quickly, avoiding full blob pulls for base images.

**Key Features**:
- Build images without Docker daemon
- No full blob pull for base images
- Supports artifact image builds
- Compatible with Dockerfile/Containerfile
- CI pipeline friendly

## Core Components

### 1. Engine (`pkg/engine.go`)

**BuildEngine** struct manages:
- `BuildContext`: Map of build contexts (image-ref, tarball-ref, path-ref)
- `GlobalArg` / `LocalArgs`: ARG variable expansion
- `Env`: Per-stage environment variables
- `LayerType`: Media type for layers (Docker/OCI)

**Key methods**:
- `AddBase()`, `AddTarball()`, `AddFolder()`: Register build contexts
- `expandArg()`, `expandGlobalArg()`: Variable expansion
- `AllocLocalEnv()`: Initialize stage environment from base image

### 2. Build Process (`pkg/build.go`)

**Build()** function flow:
1. Start from `empty.Image`
2. Parse Dockerfile into stages
3. For each stage:
   - Pull base image via `crane.Pull()`
   - Detect layer media type (Docker/OCI)
   - Process commands:
     - **COPY**: Local files → tarball layer, or `--from` with layer diffing
     - **ENV**: Variable expansion with `$VAR` support
     - **ARG**: Build-time arguments
     - **RUN**: (TODO - placeholder)
   - Update config, annotations, and history
4. Apply build options (push, save, print)

### 3. Copy Handling (`pkg/copy.go`)

**`doCopy()`** supports:
- Local files: Creates tarball via `createBlob()`, appends as layer
- `COPY --from=image`: Rebase-style layer diffing via `subBaseImage()`
- `COPY --from=tarball`: Extract and filter tarball entries

**`subBaseImage()`**: Computes diff layers between orig and base images.

### 4. Tarball (`pkg/tarball.go`)

**Tarball** struct handles:
- Creating tarballs from filesystem paths
- Copying with path transformations (`ReplacePrefixPath`)
- `ChownOption`, `ChmodOption` for permissions

### 5. CLI (`cmd/`)

- **`root.go`**: Legacy command with flags (image-base, tarball, folder)
- **`build.go`**: Main `cigno build` command
  - Flags: `--file`, `--tag`, `--push`, `--build-arg`, `--env-strategy`
  - Env strategy: `keep` | `refresh`

## Build Context Types

| Type | Description |
|------|-------------|
| `ImageRef` | Remote image reference (e.g., `alpine:latest`) |
| `TarballRef` | Local tarball file |
| `PathRef` | Local folder path |

## Build Options

```go
type BuildOption func(img v1.Image) error

func PrintHistoryOption() // Print layer info
func OutFileOption()      // Save to tar file
func PushOption()         // Push to registry
```

## Key Design Patterns

1. **Option Pattern**: `BuildOption` for post-build actions
2. **Functional Options**: `TarOption` for tarball transformations
3. **Layer Diffing**: `subBaseImage()` computes deltas for rebase
4. **Annotation Tracking**: Stores base image digest/name in OCI annotations
